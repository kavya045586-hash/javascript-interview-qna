## 🌐 What is a Browser?

A browser is software that lets you access and view websites on the internet.
It takes the code (HTML, CSS, JavaScript) of a website and turns it into the
visual page you see and interact with.

**Simple analogy:** If the internet is a huge library of books, a browser is
the pair of eyes and hands that lets you open a book, read it, and turn pages.

### Types of Browsers
- **Google Chrome** — most widely used, made by Google
- **Mozilla Firefox** — open-source, privacy-focused
- **Safari** — Apple's browser, default on Mac/iPhone
- **Microsoft Edge** — Microsoft's browser, comes with Windows
- **Opera** — lightweight, has built-in VPN and ad-blocker

Each browser has its own **JavaScript engine** that runs JS code:
| Browser | JS Engine |
|---|---|
| Chrome / Edge | V8 |
| Firefox | SpiderMonkey |
| Safari | JavaScriptCore |

---

## 📜 What is JavaScript?

JavaScript is a programming language that makes websites **interactive**.

- **HTML** = the skeleton (structure of the page)
- **CSS** = the skin/clothes (how it looks)
- **JavaScript** = the brain and muscles (how it behaves and responds)

Without JavaScript, a webpage would just sit there — no button clicks, no
pop-ups, no live updates, no form validation.

---

## ⚙️ How Does JavaScript Run?

1. You write JavaScript code in a `.js` file (or inside `<script>` tags in HTML)
2. The browser's **JavaScript engine** (like V8 in Chrome) reads the code
3. The engine converts it into machine code the computer understands
4. It executes the code **line by line**, top to bottom, inside the browser

JavaScript can also run **outside the browser** using **Node.js** — this lets
developers use JS to build servers and backend applications too.

---

## 💡 Where is JavaScript Used?

- **Websites** — interactive buttons, forms, animations, live search
- **Web apps** — Gmail, Google Maps, Netflix UI
- **Mobile apps** — using frameworks like React Native
- **Servers/backend** — using Node.js
- **Games** — simple browser-based games
